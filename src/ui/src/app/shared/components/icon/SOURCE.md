# Material Icon Sources

The SVG path data in this component comes from the filled 24 px icons in the
Google Material Design Icons repository.

- Repository: https://github.com/google/material-design-icons
- Commit: `819d78680a849ceef4c78f863d8753e3160b7c89`
- Icons: `add`, `check_circle`, `close`, `delete`, `edit`, `error`, `info`,
  `logout`, `menu`, `publish`, `save`, `upload`, `visibility`, and `warning`
