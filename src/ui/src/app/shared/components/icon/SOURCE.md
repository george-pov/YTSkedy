# Material Symbol Source

The `app-icon` component renders Angular Material `mat-icon` with a self-hosted
subset of the official Google Material Symbols Outlined font.

- Supported names: `supportedIconNames` in `icon.ts`
- Font source and checksum:
  `src/ui/public/fonts/material-symbols-outlined/SOURCE.md`
- Maintenance workflow: `docs/ui/development/icons.md`
