# YTSkedy

YTSkedy is an application for automating the creation and scheduling of YouTube streams.

## For Developers

This README is the human-facing entry point for setup, usage, and project
status. Durable architecture and domain context live in `CONTEXT.md`. AI agent
operating instructions live in `AGENTS.md`.

## Current Status

The project is in early development and currently contains a .NET console app
POC under `src/`.

## Build

```powershell
dotnet build src/YTSkedy.slnx
```
